# 移花接木 (Keyword Replacer)

一个极简的 SillyTavern 扩展：按规则**永久**替换聊天里的关键词，直接改写聊天数据并保存——关掉扩展、重开酒馆都不会变回去。

名字取自「移花接木」：把 A 词换成 B 词，就像把枝头换掉。

常见用法：把 AI 总爱复读的词换掉，比如「嫉妒 → 忌度」。

## 功能

- 支持**多条规则**（一行一条）
- 新消息 / 新刷新（swipe）**自动永久替换并保存**
- 一键**扫描当前聊天**，修复已有消息
- 简单、轻量：没有轮询、没有 DOM 全量扫描
- 改的是聊天数据本身，**AI 也不会再看到原词**（防复读）

## 安装

### 方式一：通过 GitHub 安装（推荐）

在 SillyTavern 里：**扩展 → 安装扩展**，填入仓库地址：

```
https://github.com/SweetKeke/yihuajiemu
```

安装后刷新页面，在扩展列表里启用「移花接木」。

### 方式二：手动安装

把整个仓库文件夹放进：

```
SillyTavern/public/scripts/extensions/third-party/yihuajiemu
```

（或 `SillyTavern/data/default-user/extensions/yihuajiemu`）

然后重启 / 刷新 SillyTavern，启用扩展。

## 使用

在扩展面板里找到「移花接木」，规则箱里每行写一条：

```
# 每行一条：查找=>替换
嫉妒=>忌度
某个词=>替换成这个
要删掉的词=>
# # 开头是注释，不会生效
```

- `查找=>替换`：把「查找」换成「替换」
- 右侧**留空**：直接删除该词
- `#` 开头：注释

写好后：

- **新消息**：收到 / swipe 时自动永久替换，无需操作；
- **已有消息**：点「扫描当前聊天」批量处理。

## 说明 / 限制

- 只处理**消息正文**（`mes`）和**备选回复**（`swipes`）；
- 不处理世界书、角色卡、预设等其他数据；
- 规则是**纯文本**替换（不是正则）。
