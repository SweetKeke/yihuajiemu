# 移花接木

一个轻量的 SillyTavern 扩展：按规则**永久**替换或删除聊天内容中的关键词。

替换直接写入聊天数据并保存，关闭扩展或重启 SillyTavern 后不会还原。

## 功能

- 多组规则，可单独启用或停用
- 新消息与重新生成的回复会自动处理并保存
- 可一键扫描当前聊天，处理已有消息
- 规则支持两种写法：组合写法 / 字面写法
- 替换内容支持多行随机
- 支持规则的导入与导出（JSON）
- 无定时轮询，开销极小

## 安装

### 通过 GitHub 安装

1. 打开 SillyTavern，进入 **扩展 → 安装扩展**
2. 填入仓库地址：

   ```
   https://github.com/SweetKeke/yihuajiemu
   ```

3. 安装完成后刷新页面，在扩展列表中启用「移花接木」

### 手动安装

将本仓库放入 SillyTavern 的扩展目录之一：

```
public/scripts/extensions/third-party/yihuajiemu
data/default-user/extensions/yihuajiemu
```

重启 SillyTavern 后启用。

## 使用

打开顶部魔法棒菜单，点击「移花接木」。

- 左侧为规则组，可新建、启用/停用、删除
- 右侧为当前组的规则，点击规则行即可编辑
- 每条规则包含：备注、匹配方式、查找（每行一条）、替换（每行一条）
- 「替换」留空时，命中的内容会被直接删除

## 两种写法

### 组合写法

| 写法 | 含义 |
| --- | --- |
| `{词1,词2,词3}` | 任选其一 |
| `词1,词2,词3` | 同上，逗号分隔 |
| `\|` | 或 |
| `?` | 前一项可选，如 `{般,一样}?` |
| `*` | 通配：最多 15 个字符，遇到标点或换行即停止 |
| `\` | 转义：`\,` `\{` `\}` `\?` `\|` `\\` 表示字符本身 |

示例：

```
{突然,猛地}{一顿,一颤}?
```

### 字面写法

按字面匹配，`{}`、`|`、`?`、逗号都当作普通字符。

## 随机替换

「替换」里每行写一个候选，命中时**每次随机选一个**（两种写法都支持）：

```
查找：嫉妒
替换：  忌度
          芥蒂
          艳羡
```

留空则直接删除命中的内容。

## 说明

- 仅处理消息正文与备选回复
- 不处理世界书、角色卡、预设等数据
- 组合写法只支持上表列出的符号，不是完整的正则表达式

## 导入兼容

除了本扩展自己导出的 JSON，导入时也会识别「屏蔽词净化助手」的规则结构：

```json
{ "rules": [ { "name": "合集", "subRules": [ { "targets": ["..."], "replacements": ["..."] } ] } ] }
```

会按合集名分组自动转换，无需手动改写。
